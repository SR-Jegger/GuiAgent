# 交互卡片使用说明

服务启动后右下角弹出主入口卡片，支持文字/语音/预设/@path 四种输入方式，2 秒倒计时自动执行。

## UI 元素

- **标题栏**：`GUI Agent` + 折叠按钮 `▼/▶`
- **倒计时光圈**：圆形进度环 + 中心秒数（语音识别完成后显示）
- **输入框**：多行文本，placeholder 提示"语音/文字"
- **三个按钮**：`预存指令` / `🎤 语音输入` / `✓ 确认执行`
- **进展区**：上一步卡片、当前步骤卡片、状态消息
- **取消任务**：底部，运行中/倒计时中可点
- **确认弹窗**：自动决策模式触发时显示，含 确认/换一个/取消 三按钮

## 输入方式

### 1. 文字输入

- 输入框打字
- 点 `✓ 确认执行` 提交（**不支持 Enter 键**，多行框）

### 2. 语音输入

- 点 `🎤 语音输入` 开始录音，按钮变红 `🔴 正在录音...`
- 实时转写回填输入框
- 两种结束方式：
  - **静音自动检测**：说完一句话停顿，自动结束
  - **手动停止**：再点一次语音按钮
- ASR 结果会自动纠正同音错字（如"建发8686" → "剑发8686"），写回输入框
- 结束后进入 **2 秒倒计时**

### 3. 预存指令

- 点 `预存指令` 按钮展开面板，点条目填入输入框
- 配置文件：`app/popup/presets.json`
  ```json
  {"presets": ["打开Edge浏览器", "百度搜索天气预报"]}
  ```

### 4. @path 文件引用

- 输入框写 `@path/to/task.md`，提交时展开为文件全文
- 路径相对当前工作目录或绝对路径
- 支持多个 `@path` 混排
- 文件不存在则中止提交并报错
- 展开后按行解析，每行独立匹配意图

## 触发执行

| 触发方式 | 操作 | 何时可用 |
|---|---|---|
| 倒计时自动 | 语音识别完成后等 2 秒 | 仅语音输入后 |
| 立即执行 | 点 `✓ 确认执行` | 任何时候（输入框非空） |
| 取消 | 点 `取消任务` | 倒计时中 / 任务运行中 |
| 重新录音 | 点 `🎤 语音输入` | 倒计时中（取消倒计时回录音状态） |

## 支持的指令格式

### 杀伤链指令（核心场景）

dispatcher 通过数字标识 + 汉字匹配定位杀伤链，ASR 同音错字也能命中：

| 输入示例 | 命中结果 | 说明 |
|---|---|---|
| `打击剑发8686` | 剑发-8686 | 汉字+数字都对 |
| `打击建发8686` | 剑发-8686 | **ASR 错字"建发"，数字 8686 命中** |
| `8686` | 剑发-8686 | 纯数字也能命中 |
| `打击剑发8686的206平台` | 剑发-8686 / 平台 206 | 同时指定目标和平台 |
| `确认丰田-6676` | 丰田-6676 | 带短横也支持 |
| `确认206` | 不触发 | 206 是 platform_id，不误触发 target dispatcher |

命中后自动识别阶段（fix/track/target/engage/assess）执行对应操作。

**UI 纠正展示**：语音输入"打击建发8686"，卡片输入框直接显示纠正后的"打击剑发8686"，让用户在提交前确认。

### 模式切换指令

后端拦截，不走 dispatcher：

| 指令 | 作用 |
|---|---|
| `开启自动模式` / `开启自动决策` / `开启自动` | LLM 自主决策推进杀伤链（无需用户确认） |
| `开启确认模式` / `开启确认决策` / `开启确认` | LLM 决策 + 弹窗确认（推荐） |
| `关闭自动决策` / `关闭自动模式` / `关闭自动` | 关闭自主决策 |

### 自动决策确认弹窗

`开启确认模式` 下，后端 LLM 评估当前页面杀伤链状态后，若建议推进某条链，弹出：

> 建议推进 剑发-8686（平台 206 处于 track 阶段），确认吗？

三按钮：
- **确认**：推进该目标
- **换一个**：让后端重新选一条
- **取消**：不推进

## 状态说明

| 状态 | 含义 |
|---|---|
| IDLE | 空闲，等待输入 |
| RECORDING | 语音录音中 |
| CONFIRMING | 倒计时确认中（2 秒） |
| RUNNING | 任务执行中 |
| COMPLETED | 任务完成 |
| FAILED | 任务失败 |
| CANCELLED | 任务已取消 |

## 常见场景

### 场景 1：语音推进杀伤链（推荐）

1. 点 `🎤 语音输入`
2. 说"打击剑发8686"
3. 静音后自动进入 2 秒倒计时
4. 输入框显示纠正后的"打击剑发8686"
5. 倒计时结束自动执行（或点 `✓ 确认执行` 立即执行）
6. 进展区显示当前步骤

### 场景 2：手动输入 + 立即执行

1. 输入框打"打击丰田6676"
2. 点 `✓ 确认执行`
3. 立即提交执行

### 场景 3：批量任务从文件加载

1. 准备 `task.md`，每行一条指令：
   ```markdown
   打击剑发8686
   打击丰田6676
   确认剑客0332
   ```
2. 输入框打 `@task.md`
3. 点 `✓ 确认执行`
4. 后端按行解析，每行独立匹配

### 场景 4：自动决策模式

1. 输入框打"开启确认模式"，提交
2. 后端开始周期性评估页面杀伤链
3. 建议推进时弹出确认框
4. 点"确认"即推进，点"换一个"重新选，点"取消"跳过

## 注意事项

- **ASR 同音错字纠正**：仅在指令含数字标识（如 8686）且 cache 中有对应杀伤链时生效。纯语义指令（如"打开那个单据"）不纠正。
- **倒计时 2 秒**：语音识别完成后自动开始，期间可取消或立即执行。
- **单任务模式**：同时只允许一个任务运行，已有任务在执行时新提交会被忽略。
- **预设指令配置**：修改 `app/popup/presets.json` 后需重启服务生效。

## 杀伤链
1. service 层用 "8686" 找到 chain -> 拿 target_id
2. task_decomposer 层用 "剑发-8686" 重新 resolve_first 找 chain
