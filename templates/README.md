# UI 模板库

用于模板匹配的 UI 元素截图库。

## 目录结构

```
templates/
├── buttons/          # 按钮类
├── icons/            # 图标类
└── apps/             # 应用图标
```

## 添加新模板

1. 截图目标 UI 元素（尽量只截元素本身，不要多余背景）
2. 保存到对应目录，用英文命名
3. 在 template_registry.json 中注册（可选）

## 模板制作技巧

- ✅ 截取元素本身，大小适中（20x20 ~ 100x100 像素）
- ✅ 保持清晰，不要模糊
- ✅ 代表性强（避免截到动态变化的内容）
