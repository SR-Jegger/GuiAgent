## 自动化任务-任务指派
在当前打开的无人作战指挥系统页面，选择状态为巡航的飞机卡片右键点击
菜单栏中选择指派任务
在地图上随机点击一个靠地图右侧的位置执行指派


● 已完成事项总结

  1. 任务指派功能修复

  - 问题：从地图右键无人机标记可正常指派，但从下方飞机卡片右键指派无响应
  - 原因：closeContextMenu 会清空 selectedDrone，导致地图点击时条件不满足
  - 解决：
    - 修改 closeContextMenu 保留 selectedDrone
    - 新增 closeContextMenuFully 用于完全关闭菜单
    - 调整 handleDroneAction 逻辑

  2. 图标优化

  - 使用本地 /airplane.png 替换外部 SVG 图标（解决加载失败问题）
  - 为离线无人机添加灰色图标
  - 图标尺寸统一为 36x36

  3. 成功提示优化

  - 移除原生 alert 弹窗
  - 添加自定义 Toast 提示组件（绿色边框，居中显示）
  - 显示内容：指派成功、无人机 ID、目标坐标
  - 3 秒后自动消失

  4. 飞行轨迹功能

  - 使用 Polyline 绘制轨迹线
  - 红蓝相间虚线效果（两条线叠加：红色虚线 + 蓝色偏移虚线）
  - 同一架飞机多次指派时，各航点间显示连续轨迹
  - 轨迹数据按无人机 ID 分别存储
